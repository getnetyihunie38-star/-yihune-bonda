# Yihune Bonda — Version 6

Full Next.js shop project for mobile and computer.

Features:
- Amharic home/products/order pages
- Neon Postgres products and orders
- Vercel Blob image storage
- Password-protected Admin
- Admin can add product/photo, delete products, and view orders
- Responsive for Samsung A16/mobile

Setup:
1. `npm install`
2. Create a Neon database and run `db/schema.sql`
3. Copy `.env.example` to `.env.local` and fill in DATABASE_URL, BLOB_READ_WRITE_TOKEN, ADMIN_PASSWORD and SESSION_SECRET.
4. Run `npm run dev`
5. Add the same environment variables in Vercel before deploying.

Admin URL: `/admin`
